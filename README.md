# 大学物理实验报告集

本文件夹包含了大学物理实验课程的完整实验报告和相关数据，涵盖了力学、光学、电学、热学等多个物理学分支的经典实验。

## 📁 实验项目概览

### 1. 表面张力系数的测定
- **实验原理**: 拉脱法测量液体表面张力系数
- **主要内容**: 毛细管现象、液体表面能、Young-Laplace方程
- **文件结构**: 
  - 📄 实验报告 (Markdown + TeX)
  - 📊 实验数据和图片

### 2. 薄透镜焦距的测定

- **主要内容**: 几何光学、透镜成像公式、光路调节
- **文件结构**: 
  - 📄 实验报告 (Markdown + TeX)
  - 📊 实验数据和光路图
  - 📋 实验模板

### 3. 角动量守恒定律的验证
- **实验原理**: 转动惯量测量和角动量守恒验证
- **主要内容**: 刚体转动、转动惯量、角动量守恒定律
- **文件结构**: 
  - 📄 实验报告 (Markdown + TeX)
  - 📊 转动实验数据

### 4. 空气中声速的测定

  - 📄 实验报告 (Markdown + TeX)

### 5. 太阳能电池的特性与研究

  - 📄 实验报告 (Markdown + TeX)

### 6. 拉伸法测杨氏模量

## 🔧 文档格式说明

### Markdown文档 (.md)
- 原始实验报告，包含完整的实验内容
- 支持数学公式、表格、图片
- 便于在线查看和编辑

### TeX文档 (.tex)
- LaTeX格式的实验报告
- 专业的科学文档排版
- 可编译生成高质量PDF

### 编译文件
- `.aux`, `.log`, `.synctex.gz`: LaTeX编译辅助文件
- `.pdf`: 最终生成的实验报告
